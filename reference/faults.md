# Faults data set

Data set taken from ( ) and posteriorly analyzed by (Castellares et al.
2018) . The data contains the number of faults in rolls of fabric of
different lengths.

## Format

A data frame with 32 rows and 2 variables:

- nf: number of faults in rolls of fabric of different lengths.

- lroll: length of the roll.
