# The 'bellreg' package.

Bell Regression models for count data with overdispersion. The
implemented models account for ordinary and zero-inflated regression
models under both frequentist and Bayesian approaches. Theorical details
regarding the models implemented in the package can be found in
(Castellares et al. 2018) and (Lemonte et al. 2020)
